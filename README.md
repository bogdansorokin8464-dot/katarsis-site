# Катарсис · 2026.11.12.2

**Памятка Мастера для ширмы:** `/gm/screen/` открывает набор из четырёх листов A5 и одного обзорного листа A4 альбомного формата. Доступны единый PDF на пять страниц с сохранёнными размерами листов, PDF по отдельным форматам и HTML-страницы для печати; тексты собраны из текущих правил, незакреплённые решения обозначены, новые механики не добавлены.

**`/rulebook/`** — самостоятельная адаптивная и пригодная для печати книга Катарсиса. Она собирается из текущего справочника и содержит 25 глав правил, 31 навык, 212 способностей и ключей, 439 предметов снаряжения, боевую памятку и хронику мира. Поиск и фильтры работают без внешних сервисов; печать браузера позволяет сохранить книгу как PDF. Игровые тексты и механика не дублируются вручную и не расширяются новыми правилами.

Сборка книги: `npm run build:rulebook`. Команда подключена к `npm start`, `npm run dev` и `npm run deploy`. Публичная публикация из этой сессии не выполнялась.
