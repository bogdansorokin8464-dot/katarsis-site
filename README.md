# Катарсис — полный репозиторий сайта

**Версия 2026.10.28.6.** Компактная редакция: принятые правила и учёт находятся в карточках знамений и призваний. Пятистраничный бланк убран.

## Замена старых файлов

1. В GitHub Desktop нажмите **Show in Explorer**. Сохраните резервную копию этой папки.
2. Скопируйте **всё содержимое данного архива** непосредственно в открытую папку репозитория с заменой. `package.json`, `wrangler.jsonc`, `web`, `src` и `scripts` должны быть сразу в корне, а не во вложенной папке `katarsis-site`.
3. Не удаляйте `.git` и свои локальные секреты `.env`/`.dev.vars`. Архив не содержит учётных данных.
4. В GitHub Desktop появятся изменения. Введите описание → **Commit to main** → **Push origin**. При защите ветки используйте отдельную ветку и Pull Request.

Новый репозиторий GitHub создавать не нужно. Этот архив не содержит `.git`: история и адрес удалённого репозитория берутся из вашей существующей папки.

## Запуск и публикация

Node.js 20+. Из корня: `npm install`, затем `npm start`. Подготовка встроенных материалов запускается автоматически. Для Cloudflare Workers: `npm run deploy` после авторизации и настройки аккаунта. `wrangler.jsonc` находится в корне. Если хостинг ранее использовал корневую директорию `katarsis-site`, поменяйте её на корень репозитория для этого плоского архива.

Готовые изображения, шрифты, веб-страницы и материалы включены. `КАТАРСИС.html` — автономный исходник, необходимый также для повторной генерации материалов. Он находится внутри репозитория, а не рядом с ним снаружи.

Персонажи хранятся в браузере, а не в репозитории. Перед сменой домена экспортируйте коллекцию персонажей в JSON. Внешняя публикация из этой сессии не выполнялась.

## Компактная упаковка

В архиве нет node_modules, временных файлов и дублирующей сгенерированной папки web/build. Она автоматически создаётся из встроенного КАТАРСИС.html перед npm start / npm run deploy / npm test. Изображения и шрифты включены. Никаких файлов за пределами репозитория не требуется.
