ОБНОВЛЁННЫЙ САЙТ «КАТАРСИС»

В архиве полный исходный проект katarsis-site/ и КАТАРСИС.html рядом с ним. Последний файл нужен скриптам подготовки материалов и восстановления локальных ресурсов.

Карта приведена к 1850 году: отмечены прекращение существования Империи Рейгшаль, начало Смутного времени и тайное убийство её лидера южанами. Бывшие земли Рейгшаля обозначены как спорные и не присоединяются к Южным землям автоматически; Южные земли указаны как крупнейшая страна. Липотактис показан как руины с населением 0: все жители погибли, причина и виновник неизвестны.

Подготовка /gm/tools выносит растровую карту в отдельный хешированный ресурс. Последний измеренный размер web/build/materials/core.html — 21 688 906 байт, то есть на 4 525 494 байта меньше лимита Cloudflare в 25 MiB. Проверка размера включена в npm test.

Раздел /lipotaktis сохранён внутри проекта сайта вместе с мастерским помощником, раздатками, прегенами и катарсисами персонажей.

Для локальной работы: cd katarsis-site && npm install && npm test && npm start. Публикация отдельно: npm run deploy (публикует в настроенный Cloudflare аккаунт).

Тесты проекта: 23/23 пройдены. Браузерный скриншотный QA не выполнялся. Сайт не публиковался.
