# КАТАРСИС — открытый сайт для всей партии

Доступные материалы открыты без регистрации, паролей и приглашений. Supabase и другие сервисы авторизации не нужны.

**Важно:** помощник «Липотактиса», сюжетные секреты, бестиарий, карты Мастера и полный пакет раздатки тоже открыты всем. Перед мастерскими материалами есть предупреждение о спойлерах, но это не ограничение доступа.

## Адреса сайта

- `/` — главная.
- `/play/` — правила, конструктор, способности, магазин, карта мира, хроника, лист и печатные материалы игроков.
- `/gm` — открытый раздел Мастера.
- `/gm/adventure` — временно снят, отвечает 404. Исходный HTML помощника сохранён для последующего возвращения.
- `/gm/tools#gm` — ширма, генераторы и рабочее место Мастера. В том же приложении есть бестиарий.
- `/gm/handouts.pdf` — весь PDF-пакет, включая карты Мастера.
- `/updates` — обновления.

Личные листы и рабочие заметки по-прежнему сохраняются только в браузере пользователя. Открытый доступ к общим материалам не публикует эти записи. Для другого устройства используйте экспорт и импорт JSON. Входа, аналитики и рекламных cookies нет.

## Текущее состояние

Проект и живое превью готовы. **Постоянной ссылки на хостинге пока нет**: требуется публикация в вашем аккаунте Cloudflare. Supabase подключать не нужно.

## Локальный запуск

Нужен Node.js 20+. Сохраните структуру папок:

```text
материалы/
├── КАТАРСИС.html
├── Липотактис — помощник Мастера.html
├── Липотактис — вся раздатка.pdf
└── katarsis-site/
```

Из `katarsis-site`:

```bash
npm ci
npm start
```

Откройте `http://localhost:3000`. Все разделы работают без настройки аккаунтов.

Исходные HTML и PDF не меняются. Изображения и шрифты при необходимости восстанавливаются из исходного HTML автоматически — в архиве они не дублируются. Копии материалов автоматически создаются в `web/build/materials/` перед запуском и публикацией. Это генерируемая папка: при отсутствии будет собрана заново.

## Постоянная ссылка: только Cloudflare

1. Создайте бесплатный аккаунт: https://dash.cloudflare.com/.
2. В `wrangler.jsonc` проверьте `name`: выберите имя Worker, которое не перезапишет ваш существующий сайт.
3. Из папки проекта выполните:

```bash
npm ci
npx wrangler login
npm test
npm run deploy
```

Команда входа откроет Cloudflare в вашем браузере. После публикации Cloudflare напечатает настоящий постоянный HTTPS-адрес. Покупать домен не требуется.

4. Проверьте сайт в приватном окне: правила, конструктор, раздел Мастера, помощник, бестиарий, скачивание полного PDF. Можно проверить маршруты командой:

```bash
node scripts/check-deploy.mjs https://ВАШ-АДРЕС.workers.dev
```

5. Отправьте партии главный адрес. Помните: по нему можно дойти и до сюжетных секретов.

**Не отправляйте пароли, API-токены и коды входа в чат.** Для этого варианта вообще не нужны ключи Supabase, список почт и настройка cookies. Если ранее добавляли в Cloudflare секреты `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `GM_ALLOWED_EMAILS`, они больше не используются и их можно удалить в панели Worker.

Бесплатный тариф имеет ограничения. По официальным условиям, проверенным 22 октября 2026: Workers Free — до 100 000 вызовов Worker в сутки; с текущим `run_worker_first: true` запросы ресурсов тоже вызывают Worker. Один статический файл — до 25 MiB; текущие файлы укладываются. Источники: [лимиты](https://developers.cloudflare.com/workers/platform/limits/), [Static Assets](https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/).

## Перенос персонажа из старого файла

В старом HTML: «Файл → Экспорт персонажа · JSON».
На сайте: «Файл → Импорт персонажа · JSON».

Браузер не переносит хранилище локального HTML на другой домен автоматически. JSON также нужен для резервной копии, другого браузера и другого устройства. Облачной синхронизации нет.

## Обновления

- Общий адрес сайта не меняется после новой публикации.
- Изображения и шрифты имеют имена по содержимому: неизменённые файлы могут использовать браузерный кэш.
- Открытая вкладка проверяет новую версию раз в минуту и при возвращении в неё. Предлагает сохранить лист и обновиться; сама не перезагружает незаконченный лист.
- Изменения помощника или PDF подхватываются перед `npm run deploy` автоматически.
- Чтобы пересобрать публичное приложение из обновлённого исходного «Катарсиса»: `python scripts/update-from-html.py` (нужны Python и beautifulsoup4). Затем увеличьте номер версии в `src/worker.mjs`, `web/site.js`, подписях и журнале `web/*.html`; проверьте и опубликуйте.
- Перед несовместимым изменением формата сохранений нужна миграция. Публикация сама по себе не должна очищать localStorage.

## Проверки

- `npm test` — анонимная выдача всех материалов без cookies и настроек, отсутствие формы входа и удаления заметок, скачивание PDF, корректные маршруты и кэширование.
- `npx wrangler deploy --dry-run` — сборка без публикации.
- `node tests/browser-check.mjs` — браузерная проверка при запущенном сервере: все игровые разделы, сохранение, мобильные размеры, анонимное открытие помощника и бестиария, скачивание полного PDF, карта восьми помещений и уведомление об обновлении.

Для браузерной проверки дополнительно установите Playwright: `npm install --no-save --package-lock=false playwright`, затем `npx playwright install chromium`. На Linux могут понадобиться зависимости: `npx playwright install-deps chromium`.
