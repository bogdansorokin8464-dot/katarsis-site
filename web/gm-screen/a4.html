Модификаторы и повторы

Степень преимущества = +к6 · степень помехи = −к6 · максимум 5

Сложите степени всех источников; противоположные погасите 1:1; остаток ограничьте пятью. Кости к6 складываются с к20.

Успех сбрасывает счётчик. Повторное обычное перемещение без броска под это правило не попадает. Спорную однотипность решает Мастер.

Инициатива и ход

Инициатива = к20 + Реакция · 3 действия в свой ход
  • Инициатива бросается один раз в начале боя; ходят по убыванию. При равенстве выше Реакция; затем — повторный бросок между равными.
  • Реакция обновляется в начале своего следующего хода; тратится только при условии приёма.
  • Речь, атака, умение, перемещение, проверка, предмет с пояса и взаимодействие в бою расходуют действия по описанию. Стоимость 2 / 3 занимает столько же из трёх.
  • Реакция — не универсальное четвёртое действие и не бесплатная атака при движении врага.

Атака против Уклонения

К20 + подходящий навык → итог сравнить с Уклонением цели. Сначала учесть дистанцию, стоимость, условия и повтор.

20 на к20: критическое попадание, полный урон и максимальная кость урона; +1 вдохновение. Не удваивает урон и не даёт второй атаки. 1: промах независимо от Уклонения и осложнение. Половина нечётного урона округляется вверх.

Прежде чем закрыть ход

Определите ущерб, примените поглощение брони и отметьте одну доступную ячейку. Дополнительный стресс, состояния и длительность применяйте только по правилу / карточке, которое их задаёт.

Защита и движение

Уклонение = 8 + Ловкость + доспех + щит + поправки
  • Уклонение определяет попадание; броня поглощает урон после попадания. Поглощение не ниже 0; без ячеек броня его не даёт, но её бонус Уклонения сохраняется.
  • Одна броня корпуса, шлем и щит; одинаковые слоты не складываются. Длинный отдых возвращает ячейки, короткий — нет.
  • 1 клетка = 1 м; одно действие перемещения — до скорости. Диагонали: максимум 3 за весь ход. Сложная местность — скорость вдвое; отдельного действия «прыжок» нет.
  • Полуукрытие: дальний урон пополам, вверх. Полное: дальний урон до текущих ФЗ игнорируется, выше текущих ФЗ проходит полностью.
  • Лёгкая заслонка: 1 помеха Внимательности и дальним атакам. Лежащий: дальняя атака с помехой, ближняя — с преимуществом; встать — 1 действие.

Стресс и отдых

Стресс 10+: проверка к20 + Воля со сложностью от Мастера; при провале текущие МЗ становятся 1. Вместо проверки — действие на сосредоточение и череп в струне; проверка / сосредоточение стресс не снимают.

Завершённый отдых: −1к6 стресса автоматически + два хода отдыха. Короткий / длинный: ФЗ 1к4 / 2к4; МЗ 1к4 / 2к4; стресс 1к6 / 2к6; подготовка +1 / +2 вдохновения. Длительность назначает Мастер; длинный отдых возвращает все ячейки брони.

0 ФЗ: без сознания, выбрать предсмертный ход. 0 МЗ: недееспособность, но не смерть; снимается при МЗ ≥1 или завершённом отдыхе.
