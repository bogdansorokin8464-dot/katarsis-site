# Катарсис — постепенный перенос на React + TypeScript

Это **не полный переписанный сайт**. На React + TypeScript перенесены инструменты партии: поиск, журнал, режим Мастера, очередь ходов и полное резервное копирование. Компоненты живут в `client/companion/components`; модель и проверка данных — в `types.ts`, связь со старым игровым кабинетом — в `bridge.ts`, индексация — в `search.ts`. `legacy-enhancements.ts` подключает существующие подсказки и ссылки хроник к пока не перенесённым разделам.

На втором этапе в `client/builder` перенесены навигация конструктора, кнопки шагов и форма личности. На третьем этапе там же перенесён шаг характеристик: выбор способа, игровой стол с кубиком, карточки восьми характеристик, перетаскивание, назначение через список, отмена, сброс, прогресс и история. Расчёты остались прежними: броски к6, стандартный набор, бонус родной характеристики и запись в чарник выполняет исходный движок `window.KATAR_HOOKS.stats`, React только показывает его состояние и передаёт ему действия. Исходные элементы шага сохранены в документе и работают, если React-модуль не загрузился. Исходные элементы пока остаются в документе как совместимый слой: React передаёт изменения существующей логике и использует её расчёты, сохранения и выбор языков. Знамения, призвания, способности и расчёты ещё не перенесены. Сохранённые листы, формат экспорта и правила не менялись. Если React-модуль не загружен, работают прежние элементы конструктора.

Старый HTML, магазин, карта, лист персонажа, печать и Cloudflare Worker пока не переписаны. Это сделано для сохранения совместимости. Начальный вид, механика и форматы должны остаться прежними.

## Сборка

Нужен Node.js 20 или новее. В корне проекта:

```sh
npm ci
npm run build:companion
npm test
npm start
```

В результате `client/companion/main.tsx` и его зависимости собираются в `web/companion.js`. **Редактировать нужно TypeScript-файлы, не минифицированный bundle.** `web/companion.js` сохраняется в репозитории, чтобы Cloudflare мог использовать уже собранную версию. После изменения TypeScript выполните `npm run build:companion` и коммитьте и исходники, и обновлённый `web/companion.js`. `npm start`, `npm run dev` и `npm run deploy` также запускают сборку автоматически через pre-скрипты. Если используется прямая команда `npx wrangler deploy`, она берёт уже сохранённый bundle: сначала его нужно собрать.

`npm ci` в текущем окружении сообщает об уязвимостях в dev-зависимостях существующей цепочки Wrangler. `npm audit --omit=dev` сообщает 0 уязвимостей runtime-зависимостей. Обновление Wrangler и его зависимостей нужно проверить отдельно до применения `npm audit fix`.

## Данные и безопасность

Формат существующих записей `katarsis.companion.v1` и полных архивов `katarsis-companion-backup` сохранён. Ранние записи без очереди ходов читаются с пустой очередью; при ошибке чтения исходная запись не перезаписывается. Существующая библиотека персонажей по-прежнему использует IndexedDB и старый API.

Перед публикацией, а также до любого восстановления из файла, скачайте полную копию персонажей и заметок в старой версии. Данные остаются в браузере и не синхронизируются между устройствами. Мастерские заметки и резервные копии не защищены паролем.

Проверки в этой сборке: обычные `npm test`, browser-check персонажей, игровых инструментов, полного архива и поиск/журнал; отдельный `tests/react-migration-browser-check.mjs` проверяет старые заметки без очереди и сохранение повреждённых исходных данных. Браузерные тесты используют дополнительно установленный Playwright и запущенный сайт на порту 3000.

Браузерный тест `tests/react-builder-check.mjs` проверяет React-форму, прежний лист, языки, переключение персонажей, сохранение, шесть шагов и мобильную ширину. Существующие тесты конструктора и кубиков переведены на селекторы видимой React-навигации.

Браузерный тест `tests/react-stats-check.mjs` проверяет React-шаг характеристик поверх прежнего движка: способы, броски, назначение карточкой и списком, отмену, сброс, стандартный набор с родной +3, сброс при смене знамения, сохранение и перезагрузку, переключение персонажей, ширины 320–1440, уменьшенное движение, печать и работу без React-модуля. Существующий `tests/dice-table-browser-check.mjs` переведён на видимые React-элементы (`.dice-roll`, `.react-method`) и по-прежнему проверяет полёт кубика, к6 − 3, перетаскивание, клавиатуру и распределение.
